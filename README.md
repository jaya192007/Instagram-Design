# 📱 Instagram UI Design

A modern **Instagram-inspired UI design** created to practice mobile app interface design and user experience.

## ✨ Features

* 🏠 Home Feed
* 🔍 Search / Explore
* ➕ Create Post
* ❤️ Like & Comment UI
* 💬 Messaging UI
* 👤 Profile Page
* 📸 Story UI
* 📱 Responsive and clean design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎨 Design

The project focuses on a clean and simple Instagram-style interface with a user-friendly layout and modern design elements.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
